# ISSUES

## SIGReg の固有次元ミスマッチ問題

データの固有次元が潜在空間の次元より大幅に低い場合, SIGReg の等方ガウス正則化が表現の質を劣化させる (LeWM TwoRoom で確認済み). berkeley_autolab_ur5 (UR5) での予備測定で固有次元 ~6 (Two-NN) / PCA 95% 12 成分 (ViT-tiny 空間) と推定され, 192 次元の潜在空間に対して ~30 倍の乖離がある. TwoRoom (~96 倍) ほど極端ではないが, SIGReg ミスマッチが起きる条件を満たしている. Stage 1a で学習後の有効ランクを測定し, ~52/192 (27%) と確認. SIGReg/pred 損失比は ~183 で, 学習の大部分が等方化に費やされている. TwoRoom と同質の症状.

信号/ノイズ次元分離 MSE 分析により, ノイズ次元が評価指標を ~73% 希釈していることを確認. 信号次元 (51 dims) の MSE は全次元平均の ~3.7 倍で, ノイズ次元ではモデルはコピーと同等 (h=10 で pred/copy = 0.99). 予測誤差は信号方向に集中し, 信号/ノイズ MSE 比は h=1 の 11x から h=10 の 129x へ増大する.

## LeJEPA の i.i.d. 仮定と系列データのギャップ

SIGReg の理論的保証は i.i.d. 仮定に基づく. LeWM はステップワイズ適用で暗黙的に回避しているが, この分離の理論的正当性は未確立.

## データセット選択と embodiment ギャップ

当初 BridgeV2 (WidowX 250) を検証用データセットとしていたが, 最終ターゲットが UR5e であるため,"LeWM の問題" と "embodiment ミスマッチの問題" を切り分けられないリスクがあった. RoboMIND UR5e データ (25K 軌跡, LeRobot 変換対応済み) を主軸に変更. ただし RoboMIND UR5e はカメラ 1 台 (BGR 順) のみで, 深度やハンドカメラがない点が制約になりうる.
