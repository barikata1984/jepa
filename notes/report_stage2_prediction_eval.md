# Stage 2: multi-step 予測精度の評価

## 目的

Stage 1 で確認された SIGReg ミスマッチ (有効ランク ~52/192) が, 下流の予測性能にどう影響するかを定量化する. held-out エピソードでの autoregressive rollout における潜在空間 MSE の増加パターン (線形 vs 指数) を測定し, コピーベースラインと比較する.

## 実験設定

| 項目 | 値 |
|---|---|
| データセット | `lerobot/berkeley_autolab_ur5` (validation split, 8,368 シーケンス) |
| モデル | Stage 1 で 5 エポック学習済みの LeWM (チェックポイント: epoch 4) |
| 予測方式 | autoregressive rollout (予測結果を次ステップの入力に使用) |
| コンテキスト | history_size=3 フレーム |
| 予測ホライズン | 1–10 ステップ |
| ベースライン | コピー (最後のコンテキストフレームの埋め込みをそのまま返す) |
| 評価指標 | 潜在空間 MSE (192 次元平均) |
| スクリプト | `scripts/eval_multistep_prediction.py` |
| 所要時間 | ~2 分 (推論のみ) |

### 増加パターンの分析

| フィット | 残差二乗和 |
|---|---|
| 線形 (y = ax + b) | 0.0001 |
| 指数 (y = ae^{bx}) | 0.0034 |

**増加パターンは線形** (傾き ~0.016 MSE/step). 指数フィットの残差は線形の ~50 倍大きい.

## 解釈

### 1. モデルはコピーベースラインを全ホライズンで上回る

Pred/Copy 比は h=1 で 0.62, h=5 以降は ~0.22 で安定. モデルは"何も動かない"仮定よりも一貫して良い予測をしている. 学習が全く機能していないわけではない.

### 2. 誤差増加は線形であり, 指数的崩壊は観測されなかった

事前の判断基準"ホライズンに対して指数的に劣化 → 計画に使えない"には該当しない. ただし, この結果は以下の留保付きで解釈すべきである.

### 3. SIGReg ノイズ次元によるマスク効果 (重要な留保)

MSE は 192 次元の全次元平均で計算されている. Stage 1 で有効ランク ~52 と測定されたことから, ~140 次元は SIGReg が注入したノイズで占められている. これらのノイズ次元は:

- 予測可能な構造を持たないが, 分散は一定に保たれる
- 正解埋め込みもモデル予測も同様のノイズ分布を持つため, MSE への寄与が小さい
- 結果として, **情報を持つ ~52 次元の誤差がノイズ次元に希釈される**

つまり, 全次元平均 MSE は誤差を過小評価している可能性がある. 信号次元のみの MSE を計測すれば, 増加パターンがより急峻になる可能性がある.

### 4. 分散の大きさ

Pred MSE の標準偏差は平均と同程度 (h=10 で mean=0.159, std=0.139). シーケンス間のばらつきが大きく, 一部のシーケンスでは大きな予測誤差が生じている.

### 5. コピーベースラインの限界

コピーベースラインは静止シーンで有利だが, ロボット操作データでは各ステップで状態が変化するため, ホライズンに対して急速に劣化する (MSE が ~0.07/step で増加). これに対してモデルの増加率は ~0.016/step であり,"動きを予測する能力"は機能している.

## 判断

**指数的崩壊は観測されなかったが, これだけでは"ワールドモデルとして十分"とは結論できない.** 全次元平均 MSE は SIGReg のノイズ次元に希釈されており, 信号次元の誤差を過小評価している恐れがある.

### 追加実験の候補

1. **信号次元のみの MSE** — Stage 1 の特異値分解で得た主成分方向に射影し, 上位 ~52 次元のみで MSE を再計測する. ノイズ次元のマスク効果を除去できる
2. **画像空間での再構成評価** — 潜在空間 MSE は人間にとって解釈困難. デコーダ (があれば) を通して画像空間で評価すれば, 予測品質を直感的に確認できる

### Stage 0–2 の統合的知見

| Stage | 発見 | 含意 |
|---|---|---|
| 0 | 固有次元 ~6 << 潜在次元 192 | SIGReg ミスマッチの条件を満たす |
| 1 | 有効ランク ~52/192, SIGReg が損失の 94% | ミスマッチが実際に発生. 学習が等方化に駆動される |
| 2 | 予測誤差は線形増加, コピーに優位 | 表面上は機能するが, ノイズ次元が誤差をマスクしている疑い |

三段階の測定が一貫して指し示すのは, **SIGReg が 192 次元の潜在空間を"埋める"ために ~140 次元をノイズで満たしている** という構造. このノイズは予測損失の最適化を阻害し (Stage 1: 損失の 94% が等方化), 同時に評価指標を希釈する (Stage 2: 全次元平均 MSE).
